# Skills för verktyg

Använd [develop-tool](develop-tool/SKILL.md) för ett faktiskt beställt Topal-verktyg eller en rättelse i ett befintligt sådant. Den omfattar behov, lösningsval, implementation, felhantering, verifiering och relevanta livscykelfrågor.

Verktygets specifika tekniska underlag skapas nära dess implementation när det behövs. [WoW-anpassningen](../../skills/anpassning.md) förklarar varför inget fullständigt fas- eller profilträd har införts i förväg. Regler och värld utvecklas med [story-skills](../../story/skills/README.md).
