# Kunskapsunderlag

Här finns forskning, designval och granskningsresultat. Spelmaterialet finns i story; återanvändbara arbetssätt finns i [skills](../skills/README.md).

| Fråga | Underlag |
| --- | --- |
| Vad har användaren beställt och vad antar vi? | [Projektdefinition](projekt.md) |
| Vad vet vi om olika kulturers föreställningar, och vad är tillagt? | [Kulturunderlag](kulturunderlag.md) |
| Vad bygger kartor, metafysik, regler och äventyr på? | [Världsunderlag](varldsunderlag.md) |
| Vilka källor har använts och hur långt räcker de? | [Källor](kallor.md) |
| Hur skiljer sig reglerna från Fate? | [Designval](designval.md) |
| Hur har historiesegment och gästspel anpassats? | [Gemensam bakgrund](gemensam-bakgrund.md) |
| Vilka väsen kan samtala, och vilka skapade språk passar dem? | [Väsen och språk](vasen-och-sprak.md): förteckning och föreslagna parningar |
| Hur fungerar tregrunden och vilka alternativ finns? | [Magins grund](magins-grund.md) |
| Vad har kontrollerats och vad behöver provspelas? | [Granskning av spelmaterialet](granskning.md) |
| Hur har processkompletteringen granskats? | [Processgranskning](processgranskning.md) |

Underlag länkar till berörd speltext och anger skillnaden mellan belägg och världsval. Följ [forskningsunderlag och speltext](../skills/referenser/forskning-och-speltext.md) när sådant innehåll ändras. WoW:s lokala anpassning och dess skäl finns i [skills/anpassning.md](../skills/anpassning.md).
