# Skills för Fornvyr

Börja i [AGENTS.md](../AGENTS.md). Välj arbetsflöde efter uppgiften och läs bara berörda delar. Dessa repositorylokala skills läses via länkarna här; de förutsätter ingen global installation eller automatisk registrering i en agents verktygslista.

| När | Skill | Resultat |
| --- | --- | --- |
| Nytt uppdrag eller korrigerad avsikt | [handle-request](handle-request/SKILL.md) | Avgränsning, berörda arbetsflöden och kontroller |
| Historisk uppgift eller annat kunskapsgap | [research-knowledge](research-knowledge/SKILL.md) | Källstöd och avgränsningar i knowledge |
| Leverans eller ändring behöver granskas | [verify-output](verify-output/SKILL.md) | Kontroller och deras faktiska begränsningar |
| Brist i processen eller återkommande friktion | [run-methodology-retrospective](run-methodology-retrospective/SKILL.md) | Orsak, avgränsad processändring och spårbar motivering |
| Värld, kulturer eller äventyr | [develop-story](../story/skills/develop-story/SKILL.md) | Sammanhängande speltext och tillhörande kunskapsunderlag |
| Regler, magimekanik eller pedagogiska exempel | [develop-rules](../story/skills/develop-rules/SKILL.md) | Begripliga regler med kontrollerade följder |
| Faktiskt beställt programverktyg eller fel i ett sådant | [develop-tool](../engineering/skills/develop-tool/SKILL.md) | Topal-verktyg med spårning till behov, regler och verifiering |

[WoW-anpassningen](anpassning.md) förklarar ursprung, lokala ändringar och avgränsningar. [Forskningsunderlag och speltext](referenser/forskning-och-speltext.md) är den gemensamma instruktionen för användarens uppdelning. Läs den vid forskning, världsskrivande, regelutveckling och granskning av sådant innehåll.

Processförändringar lämnas för mänsklig granskning i PR. Agenten får färdigställa och kontrollera förslaget inom uppdraget; den behöver inte inhämta samma tillstånd igen. Förslaget kan inte ge sig självt nya befogenheter.
