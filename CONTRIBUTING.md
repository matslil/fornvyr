# Bidra till Projektet

Tack för att du vill bidra! Det här repositoryt innehåller ett helt bordsrollspelsprojekt: regler, spelvärldar, äventyr, illustrationer och andra resurser. Namnen på spelet och dess världar kan ändras; instruktionerna här gäller ändå Projektet som helhet.

## 1. Vad du kan bidra med

Vi välkomnar exempelvis:

- rättelser av sakfel, stavning och språk;
- förbättringar och förslag till spelregler;
- världsbeskrivningar, personer, väsen, föremål och platser;
- äventyr och andra spelresurser;
- illustrationer, kartor och annat eget originalmaterial.

Bidrag kan föreslås via issues eller pull requests. Skicka helst separata pull requests för självständiga förändringar och beskriv vad de ändrar och varför.

## 2. Licenser: två olika situationer

**Fristående projekt:** Du behöver inte bidra till detta repository för att skapa ett eget fanäventyr eller annat fristående material. Projektets offentligt licensierade kreativa material kan återanvändas icke-kommersiellt enligt `LICENSE.md` (CC BY-NC 4.0). För kommersiell användning av skyddat material krävs ett separat avtal med rättighetsinnehavaren.

**Bidrag till det officiella repositoryt:** För att Projektansvarig ska kunna utveckla, publicera och vidarelicensiera Projektet även kommersiellt måste varje bidragsgivare godkänna `CLA.md`. Du **behåller upphovsrätten** till det du bidrar med. Projektansvarig får däremot en bred, icke-exklusiv licens, inklusive rätt att kommersialisera och vidarelicensiera Bidraget utan ytterligare tillstånd eller ersättning.

## 3. Så skickar du ett bidrag

1. Öppna gärna ett issue först om förändringen är omfattande eller riskerar att påverka etablerade regler eller världsbeskrivningar.
2. Skapa en egen branch och gör ändringen med tydliga, avgränsade commits.
3. Ange källor där det är relevant, särskilt för historiska uppgifter. Skilj historiskt belagt innehåll från spelmässiga tillägg.
4. Skapa en pull request med en kort sammanfattning, eventuella kompatibilitetseffekter och uppgifter om material från tredje part.
5. **Godkänn `CLA.md`**, se [Avtal för bidragsgivare (CLA)](#avtal-for-bidragsgivare-cla) genom den signerings- eller CLA-process som Projektansvarig anger. Bidraget kan inte accepteras innan godkännandet är dokumenterat.
6. Projektansvarig granskar och beslutar om Bidraget ska ingå. Ett accepterat bidrag kan senare redigeras, ersättas eller tas bort.

## 4. Material du inte ska skicka in utan särskilt tillstånd

- upphovsrättsligt skyddade texter, bilder, kartor eller annat innehåll som du saknar rätt att licensiera enligt `CLA.md`;
- material från andra spel eller verk som enbart får användas icke-kommersiellt;
- material som tillhör arbetsgivare, uppdragsgivare eller samarbetspartner utan nödvändigt godkännande;
- material med oklara licens- eller källförhållanden.

Om du är osäker, beskriv materialets ursprung i ett issue **innan** du skickar in det.

## 5. Vem bestämmer vad som är officiellt?

Att ett bidrag föreslås innebär inte att det blir officiellt. Projektansvarig beslutar vilka ändringar som accepteras och vilka delar av Projektet som räknas som officiella. Det hindrar inte någon från att skapa fristående verk enligt den publika licensen eller egna kommersiella avtal.

## 6. Erkännande av upphovspersoner

Ange hur du vill krediteras i din pull request, exempelvis med namn eller pseudonym. Projektansvarig ska hantera erkännande av upphovspersoner enligt tillämplig lag och publicerade licensvillkor. Git-historiken är användbar, men ersätter inte nödvändigtvis tydlig kreditering i utgivna verk.

## 7. Om du vill sälja ett fristående verk

Ett CLA behövs **inte** för ett fristående tredjepartsprojekt. Om det utnyttjar material från detta repository på ett sätt som kräver kommersiellt tillstånd, kontakta rättighetsinnehavaren för individuell licensförhandling.

## Avtal för bidragsgivare (CLA)

Vi välkomnar bidrag till projektet, inklusive förbättringar av spelregler, världsbeskrivningar, äventyr, illustrationer och annat innehåll.

För att säkerställa att projektet kan fortsätta utvecklas, publiceras och licensieras kommersiellt måste alla bidragsgivare godkänna vårt [CLA](CLA.md) innan deras bidrag kan införlivas i projektet.

### Vad innebär avtalet?

Genom att godkänna CLA:

- **Behåller du upphovsrätten** till dina egna bidrag.
- Ger du projektets ansvarige en icke-exklusiv och royaltyfri rätt att använda, ändra, distribuera, publicera och kommersialisera dina bidrag.
- Ger du projektets ansvarige rätt att vidarelicensiera dina bidrag, även under kommersiella licenser och andra licensvillkor.
- Har du fortfarande rätt att använda dina ursprungliga bidrag i egna projekt.

Avtalet innebär inte att upphovsrätten till dina bidrag överlåts till projektets ansvarige.

### Hur godkänner jag avtalet?

Vi använder [CLA Assistant](https://cla-assistant.io/) för att automatiskt hantera godkännanden av bidragsavtalet.

1. Skapa en fork av repositoryt eller en egen gren (branch).
2. Gör dina ändringar och skapa en pull request.
3. Om du inte tidigare har godkänt avtalet kommer CLA Assistant att lägga till en kommentar i din pull request med en länk till avtalet.
4. Följ länken, läs igenom avtalet och godkänn det med ditt GitHub-konto.
5. CLA Assistant uppdaterar automatiskt statusen för din pull request när godkännandet har registrerats.

**Normalt behöver du bara godkänna avtalet en gång.** Om avtalet ändras kan du behöva godkänna den nya versionen innan ytterligare bidrag kan accepteras.

En pull request kan inte införlivas i projektet förrän samtliga berörda bidragsgivare har godkänt avtalet.

### Material från tredje part

Du får endast skicka in material som du har rätt att licensiera enligt CLA.

Skicka inte in upphovsrättsskyddat material från tredje part om du inte har fått nödvändiga tillstånd, inklusive rätt till kommersiell användning och vidarelicensiering.

Om din pull request innehåller material från flera upphovspersoner måste samtliga berörda rättighetsinnehavare ha lämnat nödvändiga tillstånd.

### Fristående projekt

CLA gäller endast bidrag som skickas in för att införlivas i detta officiella repository.

Fristående äventyr, tillägg, illustrationer och andra verk som bygger på projektets innehåll omfattas inte automatiskt av CLA.

Sådana verk omfattas i stället av projektets [publika licens](LICENSE.md) och eventuella separata avtal om kommersiell användning.

**Kontakt för kommersiell licensiering:** Skapa ett ärende i GitHub i projektet med din förfrågan.
