# Skills för spelmaterial

Värld, regler och äventyr hör till berättelsespåret. De behöver olika former av granskning.

| Uppgift | Arbetsflöde |
| --- | --- |
| Värld, kultur eller äventyr | [develop-story](develop-story/SKILL.md) |
| Regler, magimekanik, exempel eller formulär | [develop-rules](develop-rules/SKILL.md) |

Båda använder [forskningsunderlag och speltext](../../skills/referenser/forskning-och-speltext.md) och [verify-output](../../skills/verify-output/SKILL.md). Källkritik finns i [research-knowledge](../../skills/research-knowledge/SKILL.md).

Den här katalogen innehåller instruktioner för agenter, inte speltext. Dess länkar till underlag är avsiktliga. [Spelmaterialets ingång](../README.md) behålls för spelaren. För beställda programverktyg används [engineering](../../engineering/README.md).
