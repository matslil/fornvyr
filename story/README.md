# Spelmaterial

Fornvyrs speltext består av [regler](regler/grundregler.md), [Mundor](varld/mundor.md) och [äventyr](aventyr/klockan-under-vadstallet.md). Börja som ny läsare med [snabbstarten](regler/snabbstart.md).

Reglerna prioriterar begriplighet, samarbete och handlingsutrymme. Världens mysterier får vara osäkra för rollpersonerna; spelaren ska kunna förstå vad ett försök kostar och vad ett tärningsslag kan avgöra.

Den gemensamma utgångspunkten finns i [projektdefinitionen](../knowledge/projekt.md). Alla nya världsfakta i version 0.1 är föreslagna; kulturernas historiska underlag ska inte förväxlas med Mundors kanon. När material senare accepteras registreras revision och beslut där, så att flera konkurrerande kanonlistor inte uppstår.
